# Política de Privacidade — MeuBolso+

**Versão da política:** [1.0]  
**Última atualização:** [17/05/2026]  
**Aplicativo:** MeuBolso+  
**Desenvolvedor/Responsável:** FrossTBee  
**Contato:** suporte.meubolso@gmail.com

## 1. Introdução

O MeuBolso+ foi desenvolvido para auxiliar no controle financeiro pessoal com foco em privacidade, simplicidade e uso local. Esta Política de Privacidade explica como o aplicativo trata informações do usuário na versão atual.

## 2. Funcionamento geral e uso offline

O MeuBolso+ foi planejado para funcionar principalmente offline. O aplicativo não exige conta online para registrar, consultar, importar ou excluir informações financeiras. No funcionamento principal atual, os dados ficam armazenados no próprio dispositivo do usuário.

## 3. Dados armazenados localmente

Para funcionar corretamente, o aplicativo pode armazenar localmente informações inseridas ou importadas pelo usuário, como transações financeiras, valores, descrições, datas, categorias, histórico, preferências de uso e cópias de segurança criadas pelo próprio usuário.

Essas informações são utilizadas apenas para a operação do aplicativo e para permitir que o usuário acompanhe sua vida financeira pessoal.

## 4. Importação de arquivos CSV e OFX

O usuário pode selecionar arquivos locais para importar extratos em CSV (valores separados por vírgula) e OFX (Open Financial Exchange). Esses arquivos são processados no próprio aparelho.

O MeuBolso+ não utiliza credenciais bancárias, não acessa contas bancárias diretamente e não envia esses arquivos para servidor externo no fluxo principal atual.

## 5. Permissões e recursos do aparelho

O aplicativo pode utilizar o seletor de arquivos do sistema para que o usuário escolha arquivos locais de importação ou backup.

O aplicativo também pode acionar autenticação biométrica, quando o usuário escolher esse recurso e quando o aparelho oferecer suporte. O MeuBolso+ não armazena dados biométricos; a verificação é tratada pelo próprio sistema operacional do aparelho.

## 6. Coleta, envio e compartilhamento de dados

No funcionamento principal atual, o MeuBolso+ não coleta dados pessoais pela internet, não envia dados financeiros para servidores externos e não compartilha dados financeiros do usuário com terceiros.

O aplicativo também não vende dados pessoais ou financeiros do usuário.

Caso versões futuras passem a utilizar serviços externos, sincronização em nuvem, análise de uso, relatórios de erro, anúncios, SDKs de terceiros ou qualquer outro recurso que altere o tratamento de dados, esta política deverá ser atualizada antes da publicação ou liberação da nova funcionalidade.

## 7. Segurança dos dados

As informações permanecem localmente no dispositivo do usuário. O usuário pode combinar os recursos do aplicativo com a proteção do próprio aparelho, como biometria, senha de desbloqueio e bloqueio de tela.

A segurança dos dados também depende dos cuidados do usuário com o aparelho, com arquivos exportados e com locais onde backups sejam salvos ou compartilhados.

## 8. Cópia de segurança, exportação e responsabilidade do usuário

O MeuBolso+ pode permitir exportar e importar cópias de segurança locais. Esses arquivos são gerados sob controle do usuário e podem conter informações financeiras pessoais.

Após a exportação, o usuário é responsável por decidir onde guardar, proteger, compartilhar ou excluir esses arquivos. O aplicativo não controla arquivos que o usuário mova para outros aplicativos, pastas, serviços de nuvem ou dispositivos.

## 9. Exclusão de dados

O MeuBolso+ possui uma opção nas configurações para excluir todos os dados do usuário armazenados localmente pelo aplicativo.

Ao utilizar essa opção, os registros e informações mantidos dentro do aplicativo são removidos do dispositivo. Essa exclusão não remove automaticamente arquivos de backup ou exportações que o usuário tenha salvo fora do aplicativo.

O usuário também pode remover dados do aplicativo pelas configurações do Android, limpando os dados do app ou desinstalando o aplicativo.

## 10. Retenção de dados

Os dados permanecem armazenados localmente enquanto o usuário mantiver o aplicativo instalado, não apagar os registros, não utilizar a opção de excluir todos os dados e não limpar os dados do aplicativo pelo sistema operacional.

Arquivos exportados ou backups permanecem disponíveis enquanto o usuário decidir mantê-los no local onde foram salvos.

## 11. Crianças e menores de idade

O MeuBolso+ não é direcionado especificamente a crianças. O aplicativo é voltado ao controle financeiro pessoal e deve ser utilizado por pessoas com capacidade para compreender e gerenciar as informações financeiras inseridas.

## 12. Alterações nesta política

Esta política pode ser atualizada para refletir mudanças futuras no aplicativo. Quando novas funções alterarem a forma de tratamento de dados, o texto deverá ser revisado e republicado.

A versão atualizada deverá estar disponível no link oficial da política: [link política].
